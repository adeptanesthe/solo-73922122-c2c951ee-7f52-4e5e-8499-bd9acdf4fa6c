# 野生动物追踪串号校正与计数台

面向野生动物视觉工程师的网页工具：纠正追踪串号（ID switch）造成的漏计 / 重复计数。
上传帧图片与检测框，标记“同只 / 异只”判断，调整关联代价参数，求解**全局最小**关联，
按轨迹条数给出动物计数；判断冲突时明确提示无解，不给计数。

## 快速启动（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

## 本地开发

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

运行测试：

```bash
pip install -r requirements-dev.txt
pytest tests/ -q
```

## 使用流程

1. **数据**：上传 1~10 张帧图片 + 1 个检测 JSON（≤30 框），或点击“加载交叉遮挡示例”。
2. **按帧查看与标记**：←/→ 键或按钮切换帧；点击两个检测框（可跨帧）后选择
   “标记为同只 / 异只”，可随时清除。
3. **代价参数**：距离权重、外观权重、每条新轨迹罚分，均可调。
4. **求解**：点击“计算最优关联”。计算期间可继续修改判断与参数；
   任何修改会立即撤下旧结果，迟到的旧结果不会覆盖新输入（按输入版本号校验）。
5. **向量一致性核查**：点击“核查向量一致性”，见下节。

## 外观向量一致性核查

用于交叉遮挡片段复核：判断哪些检测框的外观向量值得重新提取。

- **范围**：只核查“涉及”的框 ≤10 个、人工判断 ≤20 条的会话；判断必须同时
  包含同只与异只。超出范围时明确说明原因，不给建议。
- **依据**：对每条人工判断计算两框外观向量的余弦相似度。同只判断的相似度应
  整体高于异只判断。
- **可区分**：存在阈值 t 使所有同只相似度 ≥ t、所有异只相似度 < t，且两类
  间隔（最小同只 − 最大异只）≥ **0.05** 时，报告可用阈值与区间，说明无需重算。
- **不可区分**：枚举“移除哪些框”（其相关判断一并排除）的最小子集，要求移除后
  仍至少保留一条同只判断和一条异只判断。找到唯一最小框集时，列出待重算框号、
  相关判断的相似度与恢复后的可用阈值。
- **不唯一**：若存在多组同样大小的最小框集，提示“结果不唯一”，列出全部候选，
  不擅自指定某一组，也不断定向量出错。
- **不给建议**：找不到合格框集、判断缺少同只或异只、超出规模上限，或当前
  人工判断下轨迹问题本身无解时，均只说明原因，不给出重算框号。
- **时效**：改判、改参数或切换会话会立即撤下旧建议；核查任务携带输入版本号，
  迟到的旧结果不会回填（前端另有请求代次校验）。
- **非破坏性**：核查只读，不修改检测框、判断、轨迹或计数；轨迹求解与计数逻辑
  完全不变。

## 检测 JSON 格式

```json
{
  "detections": [
    {"id": "b1", "frame": 0, "rect": [x, y, w, h], "vector": [0.8, 0.1, 0.2]}
  ]
}
```

- `id`：框号（字符串或数字，全局唯一）
- `frame`：帧号，0 起，须小于上传图片数
- `rect`：`[x, y, 宽, 高]`，宽高为正
- `vector`：非零外观向量，所有框维度一致（≤512 维）

会话内可下载当前检测 JSON：`GET /api/sessions/{sid}/detections.json`。

## 模型与求解

- 约束：每框恰属一条轨迹；同一轨迹每帧至多一框；轨迹内相邻框帧差 1~2 且时间递增。
- 关联代价：`w_dist × 框中心距离平方 + w_app × (1 − 余弦相似度)`。
- 目标：所有关联代价 + 轨迹条数 × 新轨迹罚分，求**全局最小**。
- 方法：整数线性规划（SciPy `milp` / HiGHS）。
  “同只”用单位流强制可达（同轨迹），“异只”用 0/1 割变量强制不可达。
- 判断相互冲突（如两框同帧却标同只、同只与异只传递冲突）时返回**无解**，
  界面明确提示且不显示动物计数。
- 动物数 = 轨迹条数。

## 内置交叉遮挡示例

6 帧画面：A（红）与 B（蓝）沿 X 形路径相向穿行，第 3 帧 B 被 A 遮挡缺失检测、
A 的外观向量被污染。正确结果为 2 条轨迹（2 只）：B 链需跨 2 帧连接（帧 2→帧 4），
遮挡点两侧两框位置极近，朴素最近邻会在交叉点串号。
默认参数（w_dist=1、w_app=10000、罚分=15000）针对该示例调优；
上传自有数据时请按图像尺度与外观向量区分度调整权重。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 上传图片（`images`）+ 检测 JSON（`detections`），创建会话 |
| POST | `/api/example` | 创建交叉遮挡示例会话 |
| GET | `/api/sessions/{sid}` | 会话数据（含输入版本号） |
| GET | `/api/sessions/{sid}/frames/{i}` | 第 i 帧图像 |
| PUT | `/api/sessions/{sid}/judgments` | 整体替换同只/异只判断（版本 +1） |
| PUT | `/api/sessions/{sid}/params` | 更新代价参数（版本 +1） |
| POST | `/api/sessions/{sid}/solve` | 启动异步求解，返回任务 id 与输入版本 |
| GET | `/api/jobs/{job_id}` | 查询求解状态与结果（结果携带输入版本） |
| POST | `/api/sessions/{sid}/vector-check` | 启动异步向量一致性核查，返回任务 id 与输入版本 |
| GET | `/api/jobs/{job_id}` | 同上；核查任务 `kind` 为 `vector_check` |

## 说明与限制

- 会话与任务保存在进程内存中，重启即清空（单用户工具定位）。
- 上限：10 帧、30 框、200 条判断、外观向量 512 维。
- 向量核查额外限制：被判断引用的框 ≤10 个、判断 ≤20 条（枚举 2^10 个子集）。
- 求解默认 60 秒时限；本规模（≤30 框）通常在毫秒级完成。
